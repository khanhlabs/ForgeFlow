# ForgeFlow

**A Project Management Platform**

Developed by **Pham Gia Khanh**

**ForgeFlow** is a production-style project management platform built as an end-to-end engineering lab for practicing and validating modern **Software Engineering, DevOps, Cloud, Kubernetes, CI/CD, GitOps, Security, and Observability** skills.

## Features

* Organization and project management
* Project members and role management
* Task and subtask management — In Progress
* Sprint management — In Progress
* Authentication and authorization — In Progress
* Comments and collaboration — Upcoming
* Search and activity tracking — Upcoming
* AI Agent for task generation and project analysis — Upcoming
* AI-assisted sprint planning — Upcoming
* RAG-based document retrieval — Upcoming
* Frontend integration — Upcoming
* CI/CD and cloud deployment — Upcoming
* Kubernetes, GitOps, and observability — Upcoming

## Tech Stack

* **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA
* **Frontend:** React, Vite, TypeScript
* **Database:** PostgreSQL, Flyway
* **AI:** Python, FastAPI, LLM, AI Agent, Tool Calling, RAG
* **DevOps & Cloud:** Docker, GitHub Actions, AWS, Terraform, Kubernetes, Argo CD
* **Observability:** Prometheus, Grafana, Loki, OpenTelemetry

## Status

**In Progress** — Features and infrastructure are being developed incrementally.
